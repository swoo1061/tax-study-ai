## 2. 손익 시뮬레이션

```
매출:                990원
─ API 비용:          -55원
─ PG 수수료:         -36원
─ 서버 배분:          -3원 (월 1,700원 ÷ 500건 가정)

순이익:              896원 (마진 90.5%)
```


## 3. 추천 요금 체계

### 안 A: 코인제 (추천 ✅)

| 상품 | 가격 | 코인 | 문제당 단가 | 마진 |
|------|------|------|-----------|------|
| 체험팩 | 무료 | 5코인 | 0원 (미끼) | - |
| 스타터 | 990원 | 10코인 | 99원 | 39% |
| 베이직 | 4,900원 | 60코인 | 82원 | 33% |
| 프리미엄 | 9,900원 | 150코인 | 66원 | 17% |
| 프로 | 19,900원 | 400코인 | 50원 | ≈0% (충성 유저용) |

> 1코인 = 문제 1개 = 모의고사 1문제

**장점**: 사용한 만큼만 과금, 역마진 불가능, 유저 심리 부담 낮음
**사주아이 벤치마크**: 990원/건 모델과 유사

### 안 B: 건당제

| 상품 | 가격 | 내용 | 마진 |
|------|------|------|------|
| 문제 1개 | 100원 | 객관식/주관식 1문제 | 42% |
| 문제 10개 | 990원 | 10문제 팩 | 39% |
| 모의고사 1회 (1차) | 4,900원 | 20문제 + 성적분포 | 83% |
| 모의고사 1회 (2차) | 2,900원 | 5문제 + 성적분포 | 89% |
| 1일 이용권 | 2,990원 | 하루 50문제 | 8% |

### 안 C: 구독제 (주의 필요)

| 상품 | 가격 | 일일 제한 | 마진 |
|------|------|----------|------|
| 무료 | 0원 | 3문제/일 | 광고or전환용 |
| 베이직 | 9,900원/월 | 10문제/일 | 13% |
| 프로 | 19,900원/월 | 20문제/일 | ≈0% |
| 프리미엄 | 39,900원/월 | 50문제/일 | -42% ❌ |

⚠️ 구독제는 **일일 상한 없으면 확정 적자**

## 4. 추천 전략

### Phase 1: 출시 (코인제 + 무료 체험)

```
무료 회원: 매일 3코인 자동 충전 (3문제)
코인 구매: 990원 ~ 19,900원 (5개 팩)
모의고사: 20코인 (1차) / 5코인 (2차)
```

**이유**:
- 진입 장벽 최소화 (무료 3문제로 체험)
- 사주아이처럼 소액 결제 허들 낮음
- 역마진 리스크 제로
- 990원 최소 결제금액으로 PG 수수료 비율 관리

### Phase 2: 성장기 (구독 옵션 추가)

```
기존 코인제 유지
+ 월정액 9,900원 (일 10문제 + 모의고사 2회/월)
+ 월정액 19,900원 (일 20문제 + 모의고사 무제한)
```

### Phase 3: 수익 최적화

```
+ 프리미엄 콘텐츠: 기출 분석 리포트 (별도 과금)
+ 1:1 AI 튜터 (시간당 과금)
+ 학원/기업 대량 라이선스
```

## 5. 핵심 지표 목표

| 지표 | 목표 | 산식 |
|------|------|------|
| CAC (고객획득비용) | < 5,000원 | 마케팅비 ÷ 신규유저 |
| ARPU (유저당 매출) | > 3,000원/월 | 월매출 ÷ 활성유저 |
| 마진율 | > 30% | (매출-원가) ÷ 매출 |
| LTV (고객생애가치) | > 30,000원 | ARPU × 평균유지개월 |
| LTV/CAC | > 3 | 건전한 유닛이코노믹스 |
