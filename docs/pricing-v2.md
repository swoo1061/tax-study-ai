## 3. 모의고사 = 무료 미끼

### 전략

```
모의고사 자체:     무료 (코인 차감 없음)
모의고사 결과:     점수 + 등수 + 분포 → 무료 공개
모의고사 해설:     🔒 잠금 → 해설 열람에 코인 필요
```

### 미끼 → 전환 흐름

```
1. 유저 가입 (무료)
2. 모의고사 응시 (무료) → "나 60점이네, 40등/100명"
3. 틀린 문제 확인 → "왜 틀렸지?"
4. 해설 보기 클릭 → "해설 열람: 1코인/문제"
5. 코인 부족 → 코인 구매 (1,900원~)
6. 취약 주제 확인 → "이 주제 더 연습할래"
7. 문제 풀기 → 코인 소진 → 재구매
```

### 모의고사 수익 시뮬레이션

| 시나리오 | 내용 | 비용 | 수익 |
|---------|------|------|------|
| 모의고사 생성 (1차 20문제) | AI 생성 1회, 캐시 | -660원 (1회만) | 0원 |
| 100명 응시 | 서버 부하만 | ≈0원 | 0원 |
| 60명이 해설 열람 (평균 10문제) | | 0원 (이미 생성됨) | 60명×10×200원 = **120,000원** |
| 30명이 추가 문제 풀기 | 30명×10문제 | -16,500원 | 30×10×200원 = **60,000원** |
| **합계** | | **-17,160원** | **180,000원** |
| **순이익** | | | **162,840원** (마진 90%) |

→ 모의고사 1개를 무료로 풀리면, **해설 열람 + 추가 연습**으로 16만원 수익 가능

### 모의고사 해설 과금 옵션

| 옵션 | 가격 | 설명 |
|------|------|------|
| 해설 1문제 | 1코인 (200원) | 틀린 문제만 골라서 |

| 해설 전체 (5문제, 2차) | 4코인 (800원) | 20% 할인 |

## 4. 무료 체험 → 유료 전환 설계

### 무료 제공량

| 항목 | 무료 | 목적 |
|------|------|------|
| 일일 문제 | 3문제 | 맛보기 |
| 모의고사 응시 | 무제한 | 미끼 (해설은 유료) |
| 모의고사 결과 (점수/등수) | 무료 | 동기 부여 |
| 오답노트 | 무료 | 목록만 (해설은 유료) |
| 학습 기록 | 무료 | 체류 시간 증가 |
| 취약점 분석 | 무료 | "이 주제 약하네" → 구매 유도 |

### 유료 전환 포인트 (결제 유도 순간)

```
① 무료 3문제 소진 → "코인 구매하고 계속 풀기"
② 모의고사 해설 열람 → "해설 보기: 1코인"
③ 오답 문제 다시 풀기 → "재풀이: 1코인"
④ 취약 주제 집중 연습 → "10문제 생성: 10코인"
```
