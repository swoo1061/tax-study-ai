# 서버/트래픽 비용 분석

---

## 1. 현재 아키텍처

```
유저 브라우저
    │
    ▼
Vercel (Next.js)
    ├─ 정적 페이지: CDN에서 서빙 (/, /quiz, /exam 등)
    ├─ API Routes: 서버리스 함수
    │   ├─ /api/generate → Claude API 호출
    │   ├─ /api/auth/* → JSON 파일 읽기/쓰기
    │   ├─ /api/exams/* → JSON 파일 읽기/쓰기
    │   └─ /api/support → JSON 파일 읽기/쓰기
    └─ 데이터: 서버 로컬 JSON (data/)
            ↕
      Claude API (Anthropic)
```

## 2. Vercel 요금제별 비용

| 항목 | 한도 | 초과 시 |
|------|------|--------|
| 대역폭 | 100GB/월 | 서비스 중단 |
| 서버리스 함수 실행 | 100GB-시간/월 | 서비스 중단 |
| 서버리스 함수 시간 | 10초/호출 | 타임아웃 |

**⚠️ 문제**: 문제 생성 API가 10~30초 걸림 → **10초 제한 초과** → Hobby에서 불가능

## 3. 규모별 트래픽/비용 시뮬레이션

### 소규모: DAU 50명, MAU 500명

```
일일 트래픽:
  페이지 로드: 50명 × 10페이지 = 500 요청 (정적, CDN)
  API 호출: 50명 × 5문제 = 250 함수 호출
  대역폭: 500 × 200KB = 100MB/일

월간:
  대역폭: 3GB/월
  함수 실행: 7,500회 × 15초 = 31시간
  함수 메모리: 31시간 × 1GB = 31GB-시간

Vercel 비용: $20/월 (Pro 기본)
Claude API: 7,500문제 × $0.05 = $375/월
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
총 인프라: $395/월 ≈ 54만원
```

### 중규모: DAU 300명, MAU 3,000명

```

  페이지 로드: 300명 × 10페이지 = 3,000 요청

월간:
  대역폭: 18GB/월
  함수 실행: 45,000회 × 15초 = 188시간

총 인프라: $2,270/월 ≈ 311만원
```

## 6. 비용 절감 방안

### 즉시 적용 가능

| 방안 | 절감 효과 | 구현 난이도 |
|------|----------|-----------|
| **검증 에이전트 선택적 적용** | API 비용 40% 감소 | 쉬움 |
| └ 신뢰도 높은 패턴은 검증 스킵 | | |
| **모의고사 문제 캐시** | 모의고사 API 비용 → 0 | 이미 구현 |
| └ 1회 생성 후 모든 유저 재사용 | | |
| **Haiku 모델로 검증** | 검증 비용 80% 감소 | 쉬움 |
| └ 생성은 Sonnet, 검증은 Haiku | | |
| **배치 생성 + 프리캐시** | 피크 부하 분산 | 중간 |
| └ 야간에 문제 미리 생성해서 풀에 저장 | | |

### 적용 시 비용 변화

```
현재: 문제당 $0.05 (생성 $0.03 + 검증 $0.02)

최적화 후:
  생성: $0.03 (Sonnet 유지)
  검증: $0.004 (Haiku로 교체, $0.25/M input, $1.25/M output)
  검증 적용률: 50% (신뢰 높은 패턴 스킵)

  문제당 = $0.03 + ($0.004 × 0.5) = $0.032
  절감: 36%
```

| 규모 | 현재 API 비용 | 최적화 후 | 절감액 |
|------|-------------|----------|--------|
| DAU 50 | 51만 | 33만 | 18만 |
| DAU 300 | 309만 | 198만 | 111만 |
| DAU 1,000 | 1,028만 | 658만 | 370만 |

### 중장기

| 방안 | 절감 효과 | 비고 |
|------|----------|------|
| 자체 문제 DB 구축 | AI 호출 50% 감소 | 인기 주제 문제 사전 저장 |
| 로컬 LLM (Llama 등) | API 비용 → 서버 비용 | GPU 서버 필요 ($500~/월) |
