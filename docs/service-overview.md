# 시험왕 - 세무사

> AI 기반 세무사 시험 무한 문제 생성 및 풀이 플랫폼

---

## 서비스 목적

세무사 1·2차 시험 수험생에게 **무한한 연습 문제**를 제공합니다.

기존 학습 방법의 한계:
- 기출문제는 한정적 (다 풀면 끝)
- 학원 모의고사는 비쌈 (3~5만원/회)
- 문제집은 답을 외워버림

시험왕의 해결:
- AI가 **매번 새로운 문제**를 실시간 생성
- 문제당 **200원** (학원 대비 1/100)
- **8개 과목** × **무한 문제** × **즉시 해설**

## 핵심 기능

### 1. AI 문제 생성 (/quiz)
- **8개 과목**: 재정학, 세법학개론, 회계학개론, 상법·민법, 세법학1·2부, 회계학1·2부
- **1차 객관식**: 5지선다, 4가지 출제 패턴 랜덤
- **2차 주관식**: 계산형/서술형, 단계별 모범답안
- **난이도 1~5**: 기출 수준 캘리브레이션 적용
- **문제 수 선택**: 1개 / 5개 / 10개 일괄 생성
- **세션 자동 저장**: 새로고침해도 진행 상황 복구

### 2. 실전 모의고사 (/exam)
- **8개 고정 모의고사**: 1차 4과목(20문제) + 2차 4과목(5문제)
- **동일 문제**: 모든 수험생이 같은 문제를 풀어 비교 가능
- **제한시간 타이머**: 실전과 동일한 시간 압박
- **성적 분포 차트**: 전체 응시자 중 내 위치 (히스토그램)
- **AI 캐시**: 첫 응시자 접근 시 생성, 이후 재사용

### 3. 오답노트 + 북마크 (/review)
- **틀린 문제 모아보기**: 과목별 필터
- **원문 + 해설 열람**: 왜 틀렸는지 복습
- **북마크**: 중요 문제 저장
- **다시 풀기**: 같은 주제 재도전

### 4. 학습 기록 (/history)
- **과목별 정답률**: 강점/약점 파악
- **취약 주제 TOP 5**: 정답률 낮은 주제 자동 추출
- **7일 풀이 추이**: 일별 학습량 그래프
- **최근 풀이 목록**: 시간/과목/결과

### 5. 인라인 오류 신고
- **문제 화면에서 바로 신고**: 페이지 이동 없음
- **AI 즉시 재검증**: 오류 여부 자동 판별
- **오류 인정 시**: 문제 통째로 새로 생성 + 코인 환불
- **QA 피드백 루프**: 같은 유형 반복 방지

### 6. 코인 시스템
- **1코인 = 200원 = 문제 1개**
- **무료 체험**: 매일 3코인 자동 충전
- **코인팩**: 1,900원(10코인) ~ 19,900원(160코인)
- **모의고사**: 응시 무료, 해설 열람 유료 (미끼 전략)

## 기술 스택

| 계층 | 기술 | 역할 |
|------|------|------|
| 프론트엔드 | Next.js 15 + React 19 | SSR + 클라이언트 렌더링 |
| 스타일 | CSS Variables + 인라인 | 반응형 + 다크모드 |
| AI 생성 | Claude Opus 4 | 문제 생성 (최고 품질) |
| AI 검증 | Claude Sonnet 4 | 정답 재검산 + 해설 검증 |
| 인증 | bcrypt + HTTP-only 쿠키 | 이메일 가입, 카카오(예정) |
| 데이터 | 서버 JSON 파일 | 유저, 점수, 티켓, QA |
| 클라이언트 저장 | localStorage | 코인, 풀이기록, 세션 |
| 배포 (예정) | Vercel Pro | 서버리스, CDN |

## 수익 모델

```
무료 체험 (매일 3문제)
    │
    ▼ "더 풀고 싶다"
코인 구매 (1,900원 ~ 19,900원)
    │
    ▼ 문제 풀기 (1코인/문제)
    │
    ▼ "실력 확인하고 싶다"
모의고사 응시 (무료)
    │
    ▼ "왜 틀렸지?"
해설 열람 (1코인/문제) ← 미끼 전환 포인트
    │
    ▼ "이 주제 약하네"
취약 주제 집중 연습 → 코인 소진 → 재구매
```
